# Desktop PSI 月報

入口：Desktop 左側「PSI 月報」，網址 `/psi`。API `/api/psi`；Excel `/api/psi/export`。
這是即時計算的唯讀報表，不新增 PSI 儲存表、不修改資料庫結構、不補造資料。

## 資料與計算

- 月份預設 SQL Server 本月。本月截至查詢時間；歷史月份截至月底。未來月份不查詢。
- 期初：當月 `Official` 的 `OPENING_INVENTORY` 明細。期初更正已更新原明細，不能再把更正記錄加一次。
- Sell In／退貨：`Official` 匯入且 `VALID`、`APPROVED` 的交易，按 `InventoryEffectiveDate` 落在本月的正數／負數分欄；不重複計入退貨。
- Sell Out：`ACTIVE` 回報，依明細 `SellOutDate` 歸月份；包含之後補登、修改的歷史月實銷。作廢回報不計。
- 陳列：截至報表日最新的非空 `DisplayQuantity`，依回報時間、回報 ID、明細 ID 決定順序。可沿用前月快照；不是加總多次巡店，也不因只有實銷的回報而清除既有陳列。
- 期末 = 期初 + Sell In + 退貨（負數）− Sell Out。陳列已在庫存內，可銷售 = 期末 − 陳列。負庫存如實顯示，不截斷成 0。
- 沒有當月期初明細：期初、期末、可銷售保留未知，不自行把不存在的基準當零。沒有陳列快照：陳列、可銷售未知。
- 沒有實銷回報的流量為已登錄的 0；畫面明示「未回報不代表實際無銷售」。期末是依已登錄資料推算，而非盤點結果。
- 空白顯示零與未知，但 API 以數值 `0`／`null` 區分，格子提示分別說明。包含未知數的指標合計仍是未知，避免誤報完整庫存。
- `OpeningInventoryProductExclusion` 依起迄月份（含）及全體／指定客戶範圍套用，排除後才做各級加總。不更動原始庫存。
- 按截至日的客戶負責業務、員工區域歷史歸屬分組。未指派／未歸屬明列，不猜測所屬區域；不建立公司／處別新階層。
- 建議售價保留空欄，待 `Product` 欄位新增後再串接，現階段沒有虛構售價。

## 畫面

- 商品往下、客戶往右，七個 PSI 指標一格一欄，每客戶 376 px。
- 商品四欄、四層表頭、總計列固定；右側保留業務 TTL 及篩選範圍 TTL。
- 支援月份、區域、業務、大分類、型號／客戶搜尋；可切客戶明細、業務彙總、區域彙總、範圍總覽。
- 列採虛擬捲動，畫面只建立可視區附近的 DOM，但查詢、合計、匯出都包含完整篩選範圍，不分頁截斷數據。
- 每 60 秒、頁面恢復可見、按重新整理時重查；舊請求取消，錯誤時保留前次資料並明示尚未更新。
- Excel 匯出與表格共用計算函式，含分組、合計、凍結窗格與計算說明，字串不作公式執行。
- 沿用 Desktop 員工登入限制，經銷商及未登入帳號不能讀取 PSI。API 禁止快取。

## 驗證

一般測試：`.venv\Scripts\python.exe -m unittest discover -s tests -v`。

真實資料唯讀測試：設定 `LGSALE_PSI_LIVE_TEST=1` 後執行 `tests/test_psi_live.py`。

排版壓力測試：執行 `tests/psi_ui_fixture_server.py`，開啟 `http://127.0.0.1:18198/psi`。
此工具只提供合成測試資料、只監聽本機、不連 SQL；不要當成真實報表入口。

部署不需 Migration 或新增套件。更新程式後重啟 LGSale 即可。
