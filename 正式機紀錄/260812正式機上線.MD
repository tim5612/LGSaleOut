## 六、LGSale 開機自動啟動

LGSale 使用 Waitress 執行，工作排程名稱：

```text
LGSale-AutoStart
```

排程設定：

- 電腦開機時自動啟動。
- 使用 Windows `SYSTEM` 帳號。
- 不必登入 Windows。
- 不顯示黑色視窗。
- 異常結束後每分鐘嘗試重新啟動。
- 執行內容：`.venv\Scripts\python.exe -m waitress --listen=127.0.0.1:8097 LGSale:app`

檢查排程：

```powershell
Get-ScheduledTask -TaskName "LGSale-AutoStart"
```

正常運行時狀態應為 `Running`。

手動啟動或停止：

```powershell
Start-ScheduledTask -TaskName "LGSale-AutoStart"
Stop-ScheduledTask -TaskName "LGSale-AutoStart"
```

查看最近執行結果：

```powershell
Get-ScheduledTaskInfo -TaskName "LGSale-AutoStart"
```

`LastTaskResult` 為 `0` 通常表示正常完成；長期運行的網站服務在 `Running` 時不一定已產生新的結束結果。

## 八、故障排查

### 網址無法開啟或出現 502

依序檢查：

```powershell
Get-Service cloudflared
Get-ScheduledTask -TaskName "LGSale-AutoStart"
Test-NetConnection 127.0.0.1 -Port 8097
Invoke-RestMethod http://127.0.0.1:8097/api/health
```

- `cloudflared` 未執行：啟動 Cloudflare 服務。
- 排程不是 `Running`：啟動 `LGSale-AutoStart`。
- 8097 為 `False`：LGSale/Waitress 尚未成功執行。
- 健康檢查資料庫錯誤：檢查 SQL Server 服務、TCP Port及系統環境變數。

### 查詢 8097 使用狀況

```powershell
Get-NetTCPConnection -LocalPort 8097 -ErrorAction SilentlyContinue
```

不要同時手動執行 `LGSale.py` 與背景排程，否則可能因兩個程式同時占用 8097 而啟動失敗。
