# LGSale 正式機啟動與更新方式

## 一、平常開機

正式機已建立工作排程 `LGSale-AutoStart`，Windows 開機後會在背景自動啟動 LGSale，不需要雙擊 `LGSale.py`，也不需要保留 PowerShell 黑色視窗。

Cloudflare Tunnel 同樣是 Windows 服務，會隨開機自動啟動。

## 二、更新正式機程式

在正式機以「系統管理員身分」開啟 PowerShell，依序執行：

```powershell
Set-Location "C:\Users\250115_內湖桌機\Desktop\LGSale"

Stop-ScheduledTask -TaskName "LGSale-AutoStart"
git pull
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Start-ScheduledTask -TaskName "LGSale-AutoStart"
```

等待五秒後驗證：

```powershell
Start-Sleep -Seconds 5
Get-ScheduledTask -TaskName "LGSale-AutoStart"
Test-NetConnection 127.0.0.1 -Port 8097
Invoke-RestMethod http://127.0.0.1:8097/api/health
```

正常結果：

- 排程狀態為 `Running`。
- `TcpTestSucceeded` 為 `True`。
- 健康檢查的 `status` 為 `ok`，`mode` 為 `sql-server`。

最後測試正式網址：

<https://lgsaleout.superb-supplies.com.tw/>

## 三、只重新啟動程式

若沒有更新程式，只需要重新啟動 LGSale：

```powershell
Stop-ScheduledTask -TaskName "LGSale-AutoStart"
Start-Sleep -Seconds 2
Start-ScheduledTask -TaskName "LGSale-AutoStart"
```

然後執行健康檢查：

```powershell
Start-Sleep -Seconds 5
Invoke-RestMethod http://127.0.0.1:8097/api/health
```

## 四、查看或控制執行狀態

```powershell
Get-ScheduledTask -TaskName "LGSale-AutoStart"
Get-ScheduledTaskInfo -TaskName "LGSale-AutoStart"
```

手動停止：

```powershell
Stop-ScheduledTask -TaskName "LGSale-AutoStart"
```

手動啟動：

```powershell
Start-ScheduledTask -TaskName "LGSale-AutoStart"
```

## 五、注意事項

- 正式機不要再雙擊 `LGSale.py`，避免與背景排程同時占用 8097。
- 更新 Python 或 HTML 後應重新啟動排程，確保新版完整載入。
- 執行 `pip install -r requirements.txt` 不會重複安裝已存在且版本相符的套件。
- 如果更新包含 `TSQL資料` 的資料庫結構變更，必須先確認對應 SQL 的執行方式與備份需求，不能只執行 `git pull`。
- 資料庫密碼及 Cloudflare Tunnel Token 不可寫入文件或提交 Git。
